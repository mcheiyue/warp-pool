# Plan: v0.6 池内互异座位 + chen 式重抽

## Goal

恢复产品语义：

1. **换 IP = 重抽**（对齐 warp-chen：清注册态 / 整 daemon 生命周期），**不是** keep-STATE 重连。  
2. **池中成员 IP 互异且在岗**；撞 IP 时 **只处置未入座者**，**禁止拆已入座 unique 成员**（禁止 id0↔id1 互踢）。  
3. 聚合口仍只 RR/sticky 健康互异成员；出池 PARK / 守卫 reason 语义不变。

**非目标**：换 WARP 供应商、改 SOCKS 协议、大改 WebUI 视觉、下线 sticky/membership API。

---

## Product lock（用户已钉死）

| # | 语义 |
|---|------|
| P1 | 业务只连聚合口；无 API → 健康成员 RR；有 API → sticky |
| P2 | 目标是 **池内** 多出口互异且干活，不是「旁观占内存」 |
| P3 | 换 IP 对齐 chen **重抽**，不是 reconnect |
| P4 | 禁止「A 占坑 → 转 B → B 仍 A → 再转 A」互踢到无人稳定 |
| P5 | free WARP 可能给不出 N 个互异 IP → 允许 **入座数 K ≤ N**，K 为当前能互异的最大集合 |

## Evidence（现网日志 / history，pool 已停）

### 采样

| 源 | 结果 |
|----|------|
| `ip-history.jsonl` 全量 `new` | **195.192 ×60**（最高），其次 195.186/227.187/227.186/195.187 |
| reason 计数 | `rotate:restart` **253**，`rotate:hard` **25**，`observe` 42（restart:hard ≈ **10:1**） |
| `old==new` 假换号 | restart **13**，hard **2**，same-ip-unique 1 |
| 行数 | 327 条 history，id1  alone 101 条（被刷得最凶） |
| 末次 boot 日志 | id0 `ready v4=195.192 unique=true` → id1 **`v4_collision exhausted at boot`** |
| compose 默认 | `ROTATE_MODE=restart`；现网 `.env` **`HEALTH_AUTO_ROTATE=1`** |
| 配置漂移 | `.env` `WARP_INSTANCES=2`，目录 **5** 个实例（0–4） |

### 因果链（已证）

```
默认 ROTATE_MODE=restart（keep STATE）
  → 大量「换号」实为重连，195.192 粘住（history 假换号）
HEALTH_AUTO_ROTATE=1 + collision → 对冲突方（有时连带风暴）自动 rotate
  → restart 刷屏，195.192 统计被放大
boot ensure_instance_unique 对撞 IP hard/restart 连杀
  → 冷启动即「id0 入座、id1 耗尽」或全池抖动
无「已入座保护」
  → 互踢语义成立，易无人稳定
```

### 与 chen 对照

| | chen | pool 现状 |
|--|------|-----------|
| 实例 | 1 | N（现网 5） |
| 换 IP | 整容器 restart ≈ 重抽 | 默认 per-id **restart 保注册** |
| 互异 | 无 peer | 必须 peer unique |
| 结论 | 「不爱撞」= 无兄弟可撞 | 多开 + 重连 + auto = 高频 195.192 互撞 |

## Target state machine（v0.6 核心）

### 术语

- **座位 seat**：已写入 `healthy.json` backends 的成员（= 聚合成员）。  
- **候选 candidate**：进程活、probe 通、尚未入座或刚启动。  
- **重抽 redraw**：默认 **hard**（wipe STATE + registration new + start），对齐 chen。  
- **入座保护**：已在 seat 且 unique 的 id，**不得**因他人 collision 被 auto-rotate。

### 入座（boot / health）

```
对每个 candidate（按 id 升序，单飞锁）：
  probe → ip
  if ip 不与任何 seat 冲突:
    入座（meta healthy+unique，进 backends）  # 钉住，受保护
  else:
    仅对该 candidate 重抽，最多 REDRAW_MAX 次（默认 2，全 hard）
    仍冲突 → 本轮放弃入座：
      meta: alive 可 true 语义用 unique=false healthy=false
      进程保持运行（pooled=true 时不 PARK）
      不进 backends
      不 rotate 任何已 seat 成员
```

### 换 IP API / 守卫

```
POST /rotate?id=X&mode=hard|restart
  - 默认 mode=hard（compose/env ROTATE_MODE=hard）
  - 若 X 在 seat：允许（运维/守卫主动）；rotate 期间 drain 仅 X
  - 成功条件：probe 通且（与其它 seat 不冲突）；同 baseline 仅当不冲突才可接受
  - 失败：X 出 seat，其它 seat 不动
```

### 禁止

| 禁止 | 原因 |
|------|------|
| collision 触发 rotate **已 seat** id | 互踢 |
| 默认 restart 当「换 IP」 | 非 chen 重抽 |
| boot `ensure_instance_unique` 无限 hard 链 | 冷启动屠城 |
| collision auto-rotate 无上限 | 195.192 刷 history |
| 用「旁观」冒充多出口 KPI | 违背池内干活 |

### 允许的稳态

- `alive_n = 5`，`seat_n = 2~3`（CF 只给这么多互异）→ **合法**。  
- UI/API 暴露：`seats` / `alive` / `unique_ips`，不要只报 healthy/total 造成「必须 5/5」幻觉。

## Work packages

### WP0 — 默认重抽 + 配置对齐

| 项 | 动作 |
|----|------|
| `ROTATE_MODE` 默认 | `hard`（compose、`.env.example`、Dockerfile 文档） |
| 现网 `.env` | `ROTATE_MODE=hard`；`HEALTH_AUTO_ROTATE=0`（collision 不走 auto） |
| `WARP_INSTANCES` vs 目录 | 文档：热加后以目录/`desired_n` 为准；建议现网 N 先 **3** 验证互异再扩 |
| API | `POST /rotate` 无 mode 时 = hard |

**验收**：手动 rotate 日志出现 wipe STATE / registration new；history `rotate:hard` 占比上升。

### WP1 — 入座协调器（禁互踢）

**文件**：`scripts/lib.sh` 新增 `seat_assign_pass` / `is_seated`；改 `health-once.sh`、砍/弱化 boot `ensure_instance_unique`。

| 规则 | 实现要点 |
|------|----------|
| 单飞 | 沿用 health-once flock；入座扫描在锁内只做 meta+rebuild，**重抽在锁外且仅 candidate** |
| 保护 | `v4_conflicts` 的「冲突方」处理：只 `to_redraw+=candidate`，**永不**把 seat id 加入 to_rotate |
| 重抽上限 | `REDRAW_MAX=2` per candidate per pass；失败写 `seat_reject_reason=v4_collision` |
| rebuild | 仅 seat（healthy+unique+pooled+alive）进 backends |
| boot | 串行 start 全部 → **一次** seat_assign_pass；禁止 boot 内 multi-hard unique 循环 |

**验收**：

1. id0 seat=A 后 id1 也抽到 A → 只 hard id1 ≤2 次；id0 **全程在 seat**。  
2. id1 仍 A → id1 不入座，backends 仍含 id0，进程 id1 仍活（pooled=true）。  
3. 日志无「因 collision rotate 已 seat id」。

### WP2 — rotate 语义收紧

**文件**：`scripts/rotate-instance.sh`

| 项 | 动作 |
|----|------|
| 默认 hard | `_rotate_cycle` 主路径 hard；restart 仅显式 `mode=restart` |
| 成功条件 | probe 通 + 不与 **其它 seat** 冲突（自己 drain 期间不算自己冲突） |
| baseline | 同 IP：若不冲突其它 seat → 可接受并标 `rotate:same-ip-ok`；若冲突 → 计失败，不重抽别人 |
| 结束 | `rebuild_healthy_json`；**不**嵌套全量 health 再触发 auto |
| cooldown | 保留 fail streak；仅抑制 **auto** 路径 |

**验收**：hard 后 history 以新 IP 或明确 exhausted 结束；exhausted 时其它 seat 数不减。

### WP3 — AUTO 策略重写

| 触发 | v0.6 默认 |
|------|-----------|
| 进程死 + pooled | deferred **start** only（不 hard） |
| probe 失败 | failures++；达阈值可 start 一次；**不**因 probe 自动 hard |
| collision | **不** auto-rotate；只拒绝入座 + 日志 |
| 守卫/人工 | `POST /rotate` hard 仍可用 |

现网：`HEALTH_AUTO_ROTATE=0` 或拆成 `AUTO_REDRAW_ON_COLLISION=0`。

**验收**：1h 无 collision 触发的 rotate 日志；history 不再被 restart 刷屏。

### WP4 — 可观测 + API/UI 最小

| 项 | 内容 |
|----|------|
| `GET /pool` | 增加 `seats`（=members）、`alive_count`、`seat_count`；excluded 区分 `not_unique` vs `unhealthy` vs `manual` |
| `GET /health` | `healthy` = seat_count（与聚合一致） |
| WebUI | 文案：在岗座位 / 存活；避免「异常」形容仅 not_unique 的活实例（可用「未入座·IP 冲突」） |
| 日志 | `seat grant id= ip=` / `seat deny id= ip= seats=...` |

## Config defaults（v0.6）

```bash
ROTATE_MODE=hard                 # 重抽
HEALTH_AUTO_ROTATE=0             # 关闭撞 IP 自动转
AUTO_REDRAW_ON_COLLISION=0       # 显式开关，默认关
REDRAW_MAX=2                     # candidate 入座前最多 hard 次数
SUPERVISE_EXIT_ON_ALL_DEAD=0
PARK_ON_UNPOOL=1                 # 仅真正出池
# 建议现网先 N=3 验证互异率再考虑 5
WARP_INSTANCES=3
```

## Risk

| 风险 | 缓解 |
|------|------|
| hard 更慢、注册失败 | REDRAW_MAX 小；失败保留进程；日志 registration |
| CF 仍常给 195.192 | seat_n 自然 < N；不互踢；可后续加「全局 redraw 编排」 |
| 守卫仍频繁 hard | 守卫侧限频；pool 侧 per-id cooldown 对 API 可选 |
| N=5 期望过高 | 文档写明 free 出口基数；先 N=3 |

## Decision log

| 决定 | 选择 |
|------|------|
| 换 IP | 默认 **hard 重抽** |
| 撞 IP | 只 hard **未入座者**，保护 seat |
| 互异失败 | 放弃入座，进程可活，**不**拆 seat |
| auto collision | 默认关 |
| 旁观当成功 | **否** |
